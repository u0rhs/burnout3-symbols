# The value database (VDB.XML)

> Generated by `tools/gen_reference.py`.

Despite the name, `VDB.XML` is binary: Criterion's tuning values (physics, AI, camera, scoring …), stored as 32-bit hashes of their names with 32-bit values. The names are not on the disc, so the keys stay hashes until the hash function and the name strings are found in the code (the `…Attribs` classes are the likely readers).

## Format

```
u32 version   = 2
u32 n1        number of (key, value) pairs in section 1
u32 n2, n3    sizes of two further sections (not decoded)
n1 × { i32 key_hash, u32 value }   sorted by key as a signed integer; values are mostly floats
section 2 and 3: records containing the Microsoft debug-heap fills 0xFDFDFDFD and 0xCDCDCDCD,
               i.e. structures dumped from memory by a Windows tool
```
