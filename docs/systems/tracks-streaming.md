# Tracks, world and streaming

> Generated by `tools/gen_docs.py` from the Burnout 3 prototype maps and the Burnout 2 debug info. Re-running it rewrites everything except the [Notes](#notes) section at the bottom, which is kept.

**Retail addresses:** the [retail memory map](../reference/retail-memory-map.md) has the frontend globe.

**In the B3 prototype (DNAT_200 build):** 19 source files, 19 classes with methods, 146 functions, 39,152 bytes of code.
